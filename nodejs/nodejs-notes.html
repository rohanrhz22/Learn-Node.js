🌱 Set 1 · JavaScript & Node.js Basics

What Node.js is, setting up, and running your very first program.

Concept What is Node.js?

  • JavaScript usually runs in the browser.
  • Node.js lets JavaScript run on your computer / server.
  • Used for: Backend APIs, web servers, and tools & scripts.
Node.js takes JavaScript out of the browser and runs it anywhere.

Setup Install, Project & First File

You need two things installed: Node.js and VS Code. Verify Node in your terminal:

bashnode -v
📌
If you see v18.x.x or v20.x.x, you're good. Otherwise download the LTS version from nodejs.org.

Create your first program

  1. Create a folder named node-basics and open it in VS Code (File → Open Folder).
  2. Inside it, create a file index.js.
  3. Write your first line of code:
javascriptconsole.log("Hello, Node.js!");

Open the integrated terminal (Ctrl + `) and run it:

bashnode index.js
outputHello, Node.js!
🎉
Congrats — you just ran your first Node.js program!

📘 Set 2 · Control Flow & Node Basics

Decisions, loops, and the real Node feature: modules.

Logic if / else — Decision Making

A conditional statement lets your program make decisions: if something is true → do this, else → do something else.

🌧️
Real life: If it is raining → take umbrella. Else → don't take umbrella.
javascriptlet age = 18;

if (age >= 18) {
  console.log("You are allowed to vote");
} else {
  console.log("You are NOT allowed to vote");
}
  • if → keyword meaning "check a condition".
  • age >= 18 → condition (returns true or false).
  • { } → a block (group of code).
  • else → runs when the condition is false.
javascriptlet isLoggedIn = false;

if (isLoggedIn) {            // same as: if (isLoggedIn === true)
  console.log("Welcome back!");
} else {
  console.log("Please login first");
}

Logic Loops — Repeating Code

A loop repeats code again and again, so you don't write the same lines many times.

🔁 for loop (most common)

javascriptfor (let i = 1; i <= 5; i++) {
  console.log("Number:", i);
}
  • let i = 1 → starting point
  • i <= 5 → runs while true
  • i++ → add 1 each time

🔁 while loop

javascriptlet count = 1;

while (count <= 3) {
  console.log("Count is:", count);
  count++;
}
⚠️
You must manually increase count, or the loop runs forever!

Arrays + Loop together (very common)

javascriptlet languages = ["JavaScript", "Node.js", "Python"];

for (let i = 0; i < languages.length; i++) {
  console.log(languages[i]);
}
📌
Arrays start at index 0. languages.length is the number of items, and languages[i] accesses an item by index.

Big Concept Modules & require()

A module is a reusable piece of code used to organize a project. In Node.js, every file is a module. The require() function imports code from another file or module.

One file exports a function; another imports and uses it.

Step 1 — Create math.js

javascriptfunction add(a, b) {
  return a + b;
}

module.exports = add;   // share `add` with other files

Step 2 — Use it in index.js

javascriptconst add = require("./math");  // ./ = same folder, .js added automatically

let result = add(5, 3);
console.log(result);            // 8

Built-in The fs (File System) Module

fs is a built-in Node module for working with files — no ./ needed when importing.

Create data.txt containing "Hello from file", then in index.js:

javascriptconst fs = require("fs");

const content = fs.readFileSync("data.txt", "utf-8");
console.log(content);
  • readFileSync → reads the file synchronously.
  • "utf-8" → encoding (returns readable text).

⚙️ Set 3 · Node.js Core Concepts

npm, package.json, arrow functions, and the all-important callback.

Tooling npm & package.json

npm (Node Package Manager) ships with Node.js and downloads/manages libraries written by others.

📌
Think of npm like a Play Store for Node.js code.
bashnpm -v          # check npm version
npm init -y     # create package.json

The package.json is a configuration file describing your project — every real Node project has one.

json{
  "name": "node-basics",
  "version": "1.0.0",
  "main": "index.js",
  "scripts": {},
  "dependencies": {}
}
FieldMeaning
nameProject name
versionProject version
mainEntry file
dependenciesExternal libraries you install

Installing a package (example: chalk)

bashnpm install chalk

This creates a node_modules/ folder and a package-lock.json.

javascriptconst chalk = require("chalk");

console.log(chalk.green("Success message"));
console.log(chalk.red("Error message"));
⚠️
Never delete package.json — it defines your whole project.

Modern JS Arrow Functions

A shorter, cleaner way to write functions — used heavily in Node.js & React.

Normal function

javascriptfunction add(a, b) {
  return a + b;
}

Arrow function

javascriptconst add = (a, b) => {
  return a + b;
};

// even shorter:
const add = (a, b) => a + b;
javascriptconst greet = name => {
  console.log("Hello " + name);
};

greet("Rohan");

Important Callbacks

A callback is a function passed inside another function that runs later — used when reading files, fetching data, or waiting for something.

The callback is handed in early but only executes once the work is done.
javascriptfunction greet(name, callback) {
  console.log("Hello " + name);
  callback();              // executes later
}

greet("Node", function () {
  console.log("Callback executed");
});

Callbacks in real Node — fs.readFile (async)

Node.js is non-blocking: it doesn't wait, it keeps working.

javascriptconst fs = require("fs");

fs.readFile("data.txt", "utf-8", (error, data) => {
  if (error) {
    console.log("Error reading file");
    return;
  }
  console.log(data);
});
🧩
Error-first callback pattern: Node callbacks follow (error, result) — always check the error first. This pattern is everywhere in Node.js.

🚀 Set 4 · Async Concepts + Your First Server

Where Node.js becomes powerful — async control and real backend code.

Async Blocking vs Non-blocking

🛑 Blocking

Code that stops everything until it finishes.

javascriptconst data = fs.readFileSync(
  "data.txt", "utf-8");
console.log(data);
console.log("Done");
output(file content)
Done

It waits → then prints "Done".

✅ Non-blocking

Code that does not wait — it moves on.

javascriptfs.readFile("data.txt", "utf-8",
  (err, data) => {
    console.log(data);
  });
console.log("Done");
outputDone
(file content)

It doesn't wait → runs the callback later.

Core Idea The Event Loop

Node.js uses an Event Loop to manage callbacks, async tasks, and execution order. The simple mental model: run normal code first, then run async callbacks.

Async tasks go to Node APIs; when finished, their callbacks queue up and the event loop pushes them back onto the stack.
🧠
You don't need deep theory yet — just remember: Node handles many tasks without waiting.

Async Promises — Better than Callbacks

A Promise represents a task that will finish in the future. It has three states:

A promise starts pending, then settles as either resolved or rejected.
javascriptconst myPromise = new Promise((resolve, reject) => {
  let success = true;

  if (success) {
    resolve("Task completed");   // success
  } else {
    reject("Task failed");       // failure
  }
});

myPromise
  .then(result => console.log(result))   // runs on success
  .catch(error => console.log(error));   // runs on error

Promise-based file read

javascriptconst fs = require("fs").promises;

fs.readFile("data.txt", "utf-8")
  .then(data => console.log(data))
  .catch(err => console.log(err));

Modern async / await

The cleanest way to write async code — it reads like normal code but stays asynchronous.

javascriptconst fs = require("fs").promises;

async function readFileData() {
  try {
    const data = await fs.readFile("data.txt", "utf-8");
    console.log(data);
  } catch (error) {
    console.log("Error:", error);
  }
}

readFileData();
  • async → marks the function as asynchronous.
  • await → waits for the promise result.
  • try / catch → handles errors.

Backend Your First HTTP Server 🚀

Use the built-in http module to create a web server.

javascriptconst http = require("http");

const server = http.createServer((req, res) => {
  res.write("Hello from Node server!");
  res.end();
});

server.listen(3000, () => {
  console.log("Server running on port 3000");
});
  • createServer() → creates a web server.
  • req → the request from the client.
  • res → the response we send back.

Run node index.js and open http://localhost:3000 🎉

Every web interaction is a request in, a response out.

Handling different routes

javascriptconst server = http.createServer((req, res) => {
  if (req.url === "/") {
    res.write("Home Page");
  } else if (req.url === "/about") {
    res.write("About Page");
  } else {
    res.write("404 Not Found");
  }
  res.end();
});

server.listen(3000);

💥 Set 5 · Express.js — Real Backend APIs

The industry-standard framework that makes servers and routing easy.

Framework What is Express.js?

Express.js is a lightweight framework for building Node servers and APIs easily.

🚗
Analogy: Node is the engine; Express is the easy steering wheel.
bashnpm install express

Your first Express server

javascriptconst express = require("express");
const app = express();

app.listen(3000, () => {
  console.log("Server running on port 3000");
});

Routing Routes & HTTP Methods

A route is a URL path + a function that runs when accessed.

javascriptconst express = require("express");
const app = express();

app.get("/", (req, res) => {
  res.send("Home Page");
});

app.get("/about", (req, res) => {
  res.send("About Page");
});

app.listen(3000);

HTTP methods

MethodMeaning
GETGet data
POSTSend data
PUTUpdate
DELETEDelete
javascriptapp.get("/user", (req, res) => {
  res.send("User data");
});
javascriptapp.post("/user", (req, res) => {
  res.send("User created");
});
📌
You won't see POST in a browser — use a tool like Postman to test it.

Sending JSON (a real API)

javascriptapp.get("/api", (req, res) => {
  res.json({
    name: "Rohan",
    role: "Node learner"
  });
});

Routing Route Params & Query Strings

Route parameters

javascriptapp.get("/user/:id", (req, res) => {
  const userId = req.params.id;
  res.send("User ID is " + userId);
});

/user/101 → "User ID is 101"

Query parameters

javascriptapp.get("/search", (req, res) => {
  const name = req.query.name;
  res.send("Searching for " + name);
});

/search?name=node → "Searching for node"

Core Concept Middleware & JSON Input

A middleware is a function that runs before the request reaches your route.

Middleware sits in the pipeline; next() passes control onward.
javascriptapp.use((req, res, next) => {
  console.log("Request received");
  next();   // pass control to the next function
});

Handling JSON input (POST data)

javascriptapp.use(express.json());   // parse JSON bodies

app.post("/user", (req, res) => {
  const data = req.body;
  res.json({
    message: "User received",
    data: data
  });
});
