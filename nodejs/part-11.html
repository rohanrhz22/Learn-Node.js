📤 File Uploads, Streams & Buffers

Move binary data efficiently — without loading whole files into memory.

Concept Buffers — Raw Binary Data

A Buffer is a fixed chunk of raw bytes in memory. Node uses buffers for binary data like images, files and network packets.

const buf = Buffer.from("Hi");
console.log(buf);            // <Buffer 48 69>
console.log(buf.toString()); // "Hi"
console.log(buf.length);     // 2 (bytes)
📌
Strings are text; buffers are bytes. Files and network data arrive as buffers.

Concept Streams — Data in Chunks

A stream processes data piece-by-piece instead of all at once — essential for large files that wouldn't fit in memory.

Streams flow data in small chunks, keeping memory usage low and constant.

const fs = require("fs");
const stream = fs.createReadStream("big.txt", "utf-8");

stream.on("data", (chunk) => console.log("got chunk:", chunk.length));
stream.on("end", () => console.log("done"));
stream.on("error", (err) => console.error(err));

Pattern Piping Streams

pipe() connects a readable stream to a writable one — the cleanest way to copy or transform data.

const fs = require("fs");
const zlib = require("zlib");

// copy a file
fs.createReadStream("input.txt").pipe(fs.createWriteStream("copy.txt"));

// compress a file while copying (read → gzip → write)
fs.createReadStream("input.txt")
  .pipe(zlib.createGzip())
  .pipe(fs.createWriteStream("input.txt.gz"));
💡
Piping handles backpressure automatically — it pauses the source if the destination can't keep up. No manual buffering needed.

Hands-on File Uploads with Multer

multer is middleware that parses multipart/form-data (the format browsers use to upload files).

npm install multer
// src/upload.js
const multer = require("multer");

const storage = multer.diskStorage({
  destination: (req, file, cb) => cb(null, "uploads/"),
  filename: (req, file, cb) =>
    cb(null, Date.now() + "-" + file.originalname),
});

const upload = multer({
  storage,
  limits: { fileSize: 2 * 1024 * 1024 }, // 2 MB max
  fileFilter: (req, file, cb) => {
    const ok = ["image/png", "image/jpeg"].includes(file.mimetype);
    cb(ok ? null : new Error("Only PNG/JPEG allowed"), ok);
  },
});

module.exports = upload;

Single and multiple files

const upload = require("./upload");

// one file under the field name "avatar"
app.post("/avatar", upload.single("avatar"), (req, res) => {
  res.json({ file: req.file });
});

// several files
app.post("/gallery", upload.array("photos", 5), (req, res) => {
  res.json({ count: req.files.length });
});
⚠️
Always set limits and a fileFilter — unchecked uploads are a common security hole.

Setup Serving Uploaded Files

// expose the uploads folder as static files
app.use("/uploads", express.static("uploads"));
// now a file is reachable at http://localhost:3000/uploads/<name>
📌
For production, store files in cloud storage (S3, Cloudinary) instead of the server disk so they survive deploys and scale.
