🔤 Strings & Numbers

Manipulate text with string methods and work with numbers safely and precisely.

Modern strings Template Literals

Backtick strings support interpolation (${}) and multi-line text — use them everywhere.

const name = "Ada", n = 3;

const msg = `Hello ${name}, you have ${n} messages.`;
const sum = `Total: ${2 + 2}`;        // expressions allowed

const multi = `Line one
Line two`;                              // real newlines

// tagged template:
const safe = String.raw`C:\path\to`;  // no escape processing
📌
Prefer template literals over "a" + b + "c" concatenation — they’re clearer and support multi-line output natively.

Manipulation Essential String Methods

Strings are immutable — every method returns a new string.

const s = "  JavaScript  ";

s.length;              // 14
s.trim();              // "JavaScript"
s.toUpperCase();       // "  JAVASCRIPT  "
s.toLowerCase();
"abc".charAt(0);       // "a"
"abc"[0];              // "a"
"a,b,c".split(",");    // ["a","b","c"]
"abc".slice(1, 3);     // "bc"
"ab".repeat(3);        // "ababab"
"5".padStart(3, "0");  // "005"
⚠️
Because strings are immutable, s.trim() doesn’t change s — you must assign the result: s = s.trim().

Find within text Searching & Replacing

Check for and replace substrings; replaceAll and regex handle every occurrence.

const t = "the cat sat on the mat";

t.includes("cat");       // true
t.startsWith("the");     // true
t.endsWith("mat");       // true
t.indexOf("at");         // 5

t.replace("the", "a");     // first only
t.replaceAll("at", "AT");  // all
t.match(/\b\w{3}\b/g);     // ["the","cat","sat","the","mat"]
💡
Regular expressions (/pattern/flags) power advanced search/replace. replaceAll needs a string or a /g regex.

One numeric type Numbers & Their Quirks

JS numbers are 64-bit floats. That causes a famous rounding surprise.

0.1 + 0.2;             // 0.30000000000000004  !
0.1 + 0.2 === 0.3;     // false

// compare floats with a tolerance:
Math.abs(0.1 + 0.2 - 0.3) < Number.EPSILON;  // true

Number.MAX_SAFE_INTEGER;  // 9007199254740991
10n + 20n;                // 30n  (BigInt for huge integers)

1 / 0;        // Infinity
0 / 0;        // NaN
typeof NaN;   // "number"
⚠️
Never compare floats with === for equality. Use an epsilon tolerance, or work in integer cents for money.

Computation Math & Parsing

The Math object and parsing functions convert and compute.

Math.round(4.6);    // 5
Math.floor(4.9);    // 4
Math.ceil(4.1);     // 5
Math.trunc(-4.7);   // -4  (drop fraction)
Math.max(1, 9, 3);  // 9
Math.min(1, 9, 3);  // 1
Math.random();      // 0..1
Math.sqrt(144);     // 12

parseInt("42px", 10);  // 42
parseFloat("3.14rad"); // 3.14
Number("42");          // 42
Number("42px");        // NaN  (strict)
📌
parseInt stops at the first non-digit; Number() requires the whole string to be numeric. Always pass the radix 10 to parseInt.

Display Formatting Numbers

Format for humans with toFixed and the powerful Intl API.

(3.14159).toFixed(2);   // "3.14" (string!)
(1234.5).toLocaleString();// "1,234.5"

new Intl.NumberFormat("en-US", {
  style: "currency", currency: "USD"
}).format(1234.5);        // "$1,234.50"

(255).toString(16);       // "ff" (hex)
(5).toString(2);          // "101" (binary)
💡
toFixed returns a string and rounds. For locale-aware currency and units, Intl.NumberFormat is the right tool.
