🔀 Control Flow

Make decisions and repeat work with conditionals and loops.

Branching if / else if / else

Run code conditionally. The condition is coerced to a boolean (remember truthy/falsy).

const score = 82;

if (score >= 90) {
  console.log("A");
} else if (score >= 80) {
  console.log("B");
} else {
  console.log("C or below");
}
📌
Curly braces are optional for single statements, but always use them — it prevents subtle bugs when you add a second line later.

Concise branching Ternary & switch

The ternary cond ? a : b is a one-line if/else expression. switch compares one value against many cases.

Ternary

const age = 20;
const type = age >= 18
  ? "adult"
  : "minor";

// nested (use sparingly):
const t = n > 0 ? "pos"
        : n < 0 ? "neg" : "zero";

switch

switch (day) {
  case "Sat":
  case "Sun":
    console.log("weekend");
    break;
  default:
    console.log("weekday");
}
⚠️
In switch, a missing break causes fall-through to the next case. That’s occasionally useful (stacked cases) but usually a bug.

Counting for Loops

The classic for loop has three parts: initializer, condition, and update.

for (let i = 0; i < 5; i++) {
  console.log(i);   // 0 1 2 3 4
}
The condition is checked before each iteration; the update runs after the body.
💡
Declare the counter with let (not var) so each iteration gets its own scoped i — important inside closures (Part 10).

Condition-driven while & do...while

Use while when you don’t know the iteration count up front. do...while always runs at least once.

let n = 1;
while (n < 100) {
  n *= 2;     // 1,2,4,...64 -> stops at 128
}

let input;
do {
  input = prompt("Enter 'quit'");
} while (input !== "quit");
⚠️
Always ensure the condition will eventually become false — an unchanging condition creates an infinite loop that freezes the page.

Iterating collections for...of & for...in

for...of loops over values of an iterable (arrays, strings, Maps). for...in loops over keys of an object.

const colors = ["red", "green", "blue"];
for (const c of colors) console.log(c);     // values

const user = { name: "Ada", age: 36 };
for (const key in user) {
  console.log(key, user[key]);              // keys + values
}

// need the index too? use entries():
for (const [i, c] of colors.entries()) console.log(i, c);
⚠️
Use for...of for arrays, not for...in — for...in iterates string keys and can pick up inherited properties.

Loop control break & continue

break exits the loop entirely; continue skips to the next iteration.

for (const n of [1,2,3,4,5,6]) {
  if (n === 4) break;       // stop at 4
  if (n % 2 === 0) continue; // skip evens
  console.log(n);            // 1, 3
}
📌
For transforming arrays, prefer methods like map/filter (Part 5) over manual loops — they’re clearer and less error-prone.
