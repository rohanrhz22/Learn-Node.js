🔤 Strings & Formatting

Slice, transform and format text like a pro.

Core String Basics

Strings are text wrapped in quotes. They are immutable — methods return a new string rather than changing the original.

name = "Rohan"
multi = """spans
multiple lines"""

len(name)            # 6
name + " Aravind"    # concatenation
"ha" * 3             # "hahaha"
"y" in name          # True
📌
Single and double quotes are equivalent. Use triple quotes for multi-line text or docstrings.

Access Indexing & Slicing

Grab characters by index, or a substring with a slice [start:stop:step].

word = "Python"
word[0]      # "P"
word[-1]     # "n"  (last char)
word[0:3]    # "Pyt"
word[3:]     # "hon"
word[::-1]   # "nohtyP"  (reversed!)
Slicing never errors on out-of-range bounds and always returns a new string.

Toolbox Useful String Methods

Python ships dozens of handy string methods. The most common:

s = "  Hello World  "
s.strip()            # "Hello World" (trim spaces)
s.lower()            # "  hello world  "
s.upper()            # "  HELLO WORLD  "
s.replace("World", "Python")
"a,b,c".split(",")   # ["a", "b", "c"]
"-".join(["a","b"])  # "a-b"
"Hello".startswith("He")   # True
"data123".isalnum()        # True
💡
Chain methods: " Hi ".strip().lower() → "hi".

Format f-strings — modern formatting

Prefix a string with f and drop variables or expressions inside {}. This is the preferred way to build strings.

name, age = "Rohan", 27
f"{name} is {age} years old"
# "Rohan is 27 years old"

f"Next year: {age + 1}"        # inline expression
f"{name.upper()} ❤"            # call methods inside

# handy for debugging (Python 3.8+):
f"{age=}"                      # "age=27"
📌
f-strings are faster and cleaner than older % or .format() styles.

Format Number & Alignment Formatting

Add a : format spec inside the braces to control decimals, padding and alignment.

pi = 3.14159
f"{pi:.2f}"          # "3.14"  (2 decimals)
f"{1000000:,}"       # "1,000,000" (thousands)
f"{0.25:.0%}"        # "25%"   (percentage)
f"{42:05d}"          # "00042" (zero-padded)
f"{'hi':>10}"        # right-align in 10 cols
f"{'hi':^10}"        # center
SpecMeaning
.2f2 decimal places
,thousands separator
.0%percentage
05dpad number to 5 digits
> ^ <right / center / left align
💡
Format specs work in any f-string — perfect for tidy tables and money values.
