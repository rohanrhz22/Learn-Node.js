λ Functional Python

Transform data with map, filter, reduce and friends.

Transform map & filter

map applies a function to every item; filter keeps items that pass a test. Both return lazy iterators.

nums = [1, 2, 3, 4, 5]

list(map(lambda n: n * 2, nums))        # [2,4,6,8,10]
list(filter(lambda n: n % 2 == 0, nums))# [2, 4]

# combined
list(filter(lambda n: n > 4,
     map(lambda n: n * 2, nums)))       # [6, 8, 10]
📌
map/filter return iterators — wrap in list() to see all values.

Aggregate reduce

reduce (in functools) boils a sequence down to a single value by applying a function cumulatively.

from functools import reduce

reduce(lambda acc, n: acc + n, [1,2,3,4])   # 10
reduce(lambda acc, n: acc * n, [1,2,3,4])   # 24

# with a starting value
reduce(lambda a, n: a + n, [1,2,3], 100)    # 106
reduce carries an accumulator across every element.
💡
For sums and products prefer the built-ins sum() and math.prod() — clearer than reduce.

Style Comprehensions vs map/filter

Most Pythonistas prefer comprehensions over map/filter for readability.

# functional
list(map(lambda n: n*2, filter(lambda n: n%2==0, nums)))

# comprehension (more Pythonic)
[n * 2 for n in nums if n % 2 == 0]
📌
Reach for map/filter when you already have a named function to apply; otherwise a comprehension reads better.

Powerful itertools — iterator toolkit

itertools provides fast, memory-efficient building blocks for working with iterators.

from itertools import count, cycle, chain, combinations

list(chain([1,2], [3,4]))        # [1,2,3,4] join
list(combinations([1,2,3], 2))   # [(1,2),(1,3),(2,3)]

from itertools import groupby
data = [("a",1),("a",2),("b",3)]
for key, grp in groupby(data, key=lambda x: x[0]):
    print(key, list(grp))
ToolDoes

cyclerepeat forever

Powerful functools — function tools

functools adds caching and partial application.

from functools import lru_cache, partial

@lru_cache             # remembers results
def fib(n):
    return n if n < 2 else fib(n-1) + fib(n-2)
fib(50)                # instant, even though recursive

# partial: pre-fill some arguments
from functools import partial
def power(base, exp): return base ** exp
square = partial(power, exp=2)
square(5)              # 25
💡
@lru_cache turns slow recursive functions fast by memoizing past results.
