🧱 Components & Props

Pass data into components to make them reusable.

Concept What are Props?

Props (properties) are inputs to a component — like function arguments. They let one component be reused with different data.

function Greeting(props) {
  return <h1>Hello, {props.name}!</h1>;
}
Data flows one way: from parent down to child via props.
📌
Props are just an object React passes as the function's first argument.

Usage Passing Props

Pass props like HTML attributes. Strings use quotes; everything else uses { }.

function App() {
  return (
    <div>
      <Greeting name="Sandya" />
      <Greeting name="Asha" />
      <UserCard name="Ravi" age={30} isAdmin={true} />
    </div>
  );
}
⚠️
Use age={30} (a number), not age="30" (a string). Only literal text should be quoted.

Cleaner Destructuring Props

Most React code destructures props in the function signature for readability.

Without

function UserCard(props) {
  return (
    <h2>{props.name} ({props.age})</h2>
  );
}

With (preferred)

function UserCard({ name, age }) {
  return (
    <h2>{name} ({age})</h2>
  );
}
💡
Destructuring makes a component's required props obvious at a glance.

Composition The children Prop

Whatever you put between a component's tags arrives as the special children prop — the key to reusable wrappers.

function Card({ children }) {
  return <div className="card">{children}</div>;
}

function App() {
  return (
    <Card>
      <h2>Title</h2>
      <p>Anything can go inside.</p>
    </Card>
  );
}
📌
children enables layout/wrapper components like <Card>, <Modal>, <Layout>.

Fallbacks Default Props

Give props default values right in the destructuring — used when the parent omits them.

function Button({ label = "Click me", variant = "primary" }) {
  return <button className={variant}>{label}</button>;
}

<Button />                      // "Click me", primary
<Button label="Save" />         // "Save", primary
<Button label="Delete" variant="danger" />
💡
Defaults make components forgiving and self-documenting.

Rule Props are Read-Only

A component must never modify its own props. They belong to the parent. To change data over time, use state (Part 3).

function Bad({ count }) {
  count = count + 1;   // ❌ never mutate props
  return <p>{count}</p>;
}
One-way data flow keeps apps predictable and easy to debug.
⚠️
Think of props as a read-only contract from parent to child. Mutating them breaks React's data flow.
