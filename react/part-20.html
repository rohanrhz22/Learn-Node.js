🏛️ Patterns, Build & Deploy

Structure, polish and ship a production React app.

Organize Project Structure

As an app grows, organize by feature rather than by file type — related code stays together.

src/
├── components/        # shared, reusable UI
├── features/
│   ├── auth/          # components + hooks + api for auth
│   └── dashboard/
├── hooks/             # shared custom hooks
├── lib/               # api client, utils
├── routes/            # route components
├── App.tsx
└── main.tsx
💡
Co-locate a feature's components, hooks, tests and API calls in one folder. You'll find things faster and delete features cleanly.

Reusable design Component Patterns

A few patterns recur in production codebases:

  • Container/Presentational — separate data-fetching from pure UI.
  • Compound components — <Tabs><Tab/></Tabs> sharing implicit state via context.
  • Custom hooks (Part 11) — the primary way to share logic.
  • Render props / children-as-function — flexible, though hooks now cover most cases.
// keep components small & focused; extract logic to hooks
function UserProfile({ id }: { id: string }) {
  const { data, isLoading } = useUser(id);   // logic in a hook
  if (isLoading) return <Spinner />;
  return <ProfileCard user={data} />;        // pure presentation
}
📌
Favor composition and custom hooks over deep inheritance or huge prop lists.

Inclusive Accessibility (a11y)

Accessible apps reach everyone — and accessible markup makes testing (Part 18) easier too.

  • Use semantic elements: <button>, <nav>, <main> — not <div onClick>.
  • Label form fields with <label htmlFor>.
  • Provide alt text on images; manage focus on route changes.
  • Add ARIA roles only when semantics aren't enough.
💡
Run eslint-plugin-jsx-a11y and Lighthouse to catch common accessibility issues automatically.

Production bundle Building with Vite

Vite produces an optimized, minified static build ready for any host.

npm run build       # outputs to dist/
npm run preview     # locally preview the production build
The build output is plain HTML/CSS/JS — deployable to any static host or CDN.
📌
Vite handles bundling, minification, tree-shaking and asset hashing for cache-busting out of the box.

Optimize Env Vars & Code Splitting

Keep config out of code, and split big bundles so users download only what they need.

// env vars must start with VITE_
const api = import.meta.env.VITE_API_URL;

// lazy-load a route to split the bundle
import { lazy, Suspense } from "react";
const Dashboard = lazy(() => import("./routes/Dashboard"));

<Suspense fallback={<Spinner />}>
  <Dashboard />
</Suspense>
⚠️
Anything in VITE_ env vars ships to the browser — never put secrets there. Keep secrets on the server.

Go live Deploying

A built React app is static files — deployment is simple.

HostHow
Vercel / Netlifyconnect the repo; auto-build on push
GitHub Pagespush dist/ (set base path)
Cloudflare Pages / S3+CDNupload dist/ to a bucket/CDN
⚠️
For client-side routing (Part 14), configure a SPA fallback so all paths serve index.html — otherwise deep links 404 on refresh.
