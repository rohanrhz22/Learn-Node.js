🔷 TypeScript with React

Catch bugs at compile time with typed components.

Concept Why TypeScript?

TypeScript adds static types to JavaScript. In React it means autocompleted props, compile-time errors instead of runtime crashes, and self-documenting components.

npm create vite@latest my-app -- --template react-ts
  • Catch undefined and typo bugs before running
  • Autocomplete for props, hooks and events
  • Refactor safely — the compiler finds every break
  • Files use .tsx instead of .jsx
📌
The react-ts Vite template sets up everything. Existing apps can adopt TS file-by-file.

Components Typing Props

Define a type or interface for props and annotate the component.

type ButtonProps = {
  label: string;
  variant?: "primary" | "danger";   // optional union
  onClick: () => void;
};

function Button({ label, variant = "primary", onClick }: ButtonProps) {
  return <button className={variant} onClick={onClick}>{label}</button>;
}

// children:
type CardProps = { title: string; children: React.ReactNode };
💡
Use React.ReactNode for the children prop — it accepts JSX, strings, arrays and null.

useState Typing State

TypeScript usually infers state types from the initial value. Provide a generic when the type is broader than the initial value (e.g. nullable).

const [count, setCount] = useState(0);          // inferred: number
const [name, setName] = useState("");           // inferred: string

// explicit generic when initial value is null:
type User = { id: number; name: string };
const [user, setUser] = useState<User | null>(null);

const [items, setItems] = useState<string[]>([]);
⚠️
Without the <User | null> generic, useState(null) infers type null and rejects ever setting a user.

Handlers Events & Refs

React provides types for every event and DOM ref.

function handleChange(e: React.ChangeEvent<HTMLInputElement>) {
  setValue(e.target.value);
}

function handleSubmit(e: React.FormEvent<HTMLFormElement>) {
  e.preventDefault();
}

// refs are typed by the element:
const inputRef = useRef<HTMLInputElement>(null);
EventType
onChange (input)ChangeEvent<HTMLInputElement>
onClick (button)MouseEvent<HTMLButtonElement>
onSubmit (form)FormEvent<HTMLFormElement>
💡
Let your editor hint the type: hover the JSX event prop and it shows the exact signature to copy.

Advanced Typing Hooks & Context

Custom hooks and context get types too, giving end-to-end safety.

// custom hook with an explicit return type
function useToggle(initial = false): [boolean, () => void] {
  const [on, setOn] = useState(initial);
  return [on, () => setOn((o) => !o)];
}

// typed context
type AuthCtx = { user: User | null; login: (u: User) => void };
const AuthContext = createContext<AuthCtx | null>(null);

// reducer action union
type Action = { type: "inc" } | { type: "set"; payload: number };
📌
Discriminated unions for reducer actions (type Action = ...) give you exhaustive, autocompleted switch cases.
