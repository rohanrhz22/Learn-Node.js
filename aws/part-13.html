🚪 API Gateway & Serverless APIs

Create, publish and secure HTTP/REST APIs that front Lambda and other backends — fully managed.

Concept What is API Gateway?

Amazon API Gateway is a managed front door for APIs. It accepts HTTP requests, handles auth/throttling/routing, and forwards to a backend such as Lambda.

  • Fully managed — scales automatically with traffic.
  • Built-in auth, throttling, caching and logging.
  • Routes to Lambda, HTTP endpoints, or AWS services.
  • Pay per request — no idle cost.
📌
API Gateway + Lambda is the canonical way to build a serverless REST/HTTP backend with zero servers to operate.

Two flavours REST vs HTTP APIs

There’s also WebSocket APIs for real-time, two-way communication (chat, live dashboards).

💡
Default to HTTP APIs — cheaper and faster. Choose REST APIs only when you need their extra features like usage plans or request validation.

Wire it up Lambda Integration

Map routes to a Lambda function. The function receives the request as an event and returns the HTTP response.

aws apigatewayv2 create-api --name todo-api \
  --protocol-type HTTP --target arn:aws:lambda:...:function:todo

# routes -> integration -> Lambda
#   GET  /todos       -> listTodos
#   POST /todos       -> createTodo
#   GET  /todos/{id}  -> getTodo
{
  "statusCode": 200,
  "headers": { "Content-Type": "application/json" },
  "body": "{\"todos\": []}"
}
📌
With proxy integration, the whole request is passed to Lambda and your function returns the full HTTP response — simplest and most common.

Production controls Auth, Stages & Throttling

  • Authorizers — protect routes with Cognito or a Lambda authorizer (JWT).
  • Stages — deploy dev, prod versions of the API.
  • Throttling — rate + burst limits to protect backends.
  • CORS — enable browser cross-origin calls.
  • Custom domains + ACM TLS certificates.
⚠️
Always set throttling limits. Without them, a traffic spike (or abuse) can overwhelm your Lambda concurrency and your bill.

Full stack, no servers Serverless API Pattern

Client → API Gateway → Lambda → DynamoDB: a complete, auto-scaling backend with nothing to patch.

Define the whole thing as code with the AWS SAM or CDK (Part 15) and deploy with one command.

💡
This trio — API Gateway + Lambda + DynamoDB — powers a huge share of modern serverless apps. Master it and you can ship full backends fast.
